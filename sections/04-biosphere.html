每一环怎么实现

  1. 水闭环已实现
    收集冷凝水与尿液，经蒸馏、多级过滤、催化氧化后回到饮用水标准。ISS 的水回收闭环率约 98%，是整条链路里闭得最彻底的一环。
    技术详解

    水闭环：多级处理串联，覆盖尿液、汗液、冷凝水三种来源。流程大致是冷凝水收集 → 尿液真空蒸馏 → 催化氧化（去有机物）→ 离子交换 → 活性炭过滤 → 紫外或碘消毒。每一级针对一类污染物，串联起来才能把水做到可饮用。ISS 上的实测回收率约 98%，是整条闭环链路里最成熟的一环。真正的成本不在设备，而在长期运行的可靠性——任何一级出问题，整条链就停。

    创业视角

    这一环的创业位置在分布式水质监测与故障预测：舱内水系统的传感器、以及能提前判断「哪一级快失效」的模型。这类能力在地面同样刚需——工业纯水、游泳池、农村分散式供水都缺这一层。商业形态是「传感器 + 订阅式数据分析」，比卖设备本身更持久。死法：把产品定位成「航天专用」——航天客户的采购量以台计，撑不起一家公司的成本结构，必须以地面市场为基本盘。

  2. 氧与二氧化碳闭环已实现
    电解水制氧供呼吸；用 Sabatier 反应把二氧化碳和氢还原成甲烷与水，水再回去电解。氧回收约 50%，剩下的一半靠补充。这条循环已经工程化运行多年。
    技术详解

    氧与二氧化碳闭环：电解水制氧（OGA），再用萨巴蒂尔反应把 CO₂ 与 H₂ 合成 CH₄ 和 H₂O，水回用、甲烷排掉。氧回收率约 90%。注意这一步只闭环了氧，碳没有真正闭环——甲烷被排到舱外，碳链在这里断掉。所以它严格说是「氧闭环 + 碳单向流失」，而补上碳循环正是后面食物与废物两环要解决的问题。

    创业视角

    这一环的硬件由航天机构自研为主，创业空间在催化剂与反应器：萨巴蒂尔反应需要稳定的催化剂，而长期微重力运行下的催化剂寿命是真实痛点；同类能力在工业 CO₂ 加氢、合成燃料上有市场。窗口期在客户把闭环从空间站往深空扩展的时候。死法：只做航天版而不做工业化降本——航天批量的采购额养不起催化剂研发，必须用工业订单摊薄研发成本才能活。

  3. 食物闭环待突破
    走受控生态生保：水培/气雾培在密闭舱内种叶菜与小麦，用 LED 按需配光谱、把光效压到最高。难点是体积、能耗与光照面积——要喂饱一个人，种植面积本身就是一笔巨大的质量账，所以至今没有闭环。
    技术详解

    食物闭环，也是整条链路里最弱的一环。手段是受控生态种植：用 LED 光配方（特定波长组合调控生长速率与营养成分）、气培或水培的营养液循环、温湿度与气体成分控制。作物优先选单位体积产能高的（生菜、小麦、马铃薯、大豆）。真正的难点不在「种得活」，而在元素闭环——碳、氮、磷、钾与微量元素必须能循环回来，否则只是把补给从食物换成了营养液。

    创业视角

    这一环是飞船生态圈里最适合创业的方向，而且地面市场已经存在：植物工厂与设施农业。创业者的位置很实在：(1) 光配方与光谱调控（灯具 + 控制策略，按「每克干重能耗」计价）；(2) 营养液在线监测与自动配比（传感器 + 控制）；(3) 密闭环境的微生物与病虫害监测。关键策略是用地面农业的订单养航天研发，因为航天客户预算大但节奏极慢。死法：把航天当第一客户——植物工厂的商业化周期远短于航天，却因为要兼顾航天规格而把成本做高，两头都拿不到订单。

  4. 废物资源化待突破
    用生物反应器或湿式氧化把有机废物转成养分与气体，这一步是食物闭环的必要配套，否则闭环在质量上不成立。
    技术详解

    废物资源化：用酶解或湿式氧化把人体废物、包装、废弃作物转成植物可吸收的养分，让元素回到种植环节。判据不是「处理掉了」，而是回收消耗必须小于它省下的补给质量——否则闭环只是把垃圾换成了电。密闭环境里还多了两条地面不敏感的要求：病原控制与异味控制，它们在空间站里的权重远高于地面处理厂。

    创业视角

    这一环的创业位置在小型化的生物反应器与控制：能在极小体积里稳定运行的酶解或氧化装置、以及配套的臭气与微生物监测。地面市场同样存在——厨余处理、餐厨垃圾就地资源化、养殖场废弃物处理，都是政策推动、需求确定的领域。商业形态建议「卖设备 + 收处理服务费」，因为设备的可靠性风险由你承担时，客户才敢签长期合同。死法：只算设备造价不算运行成本，客户用几个月发现耗材与电费比外运还贵，合同就续不下去。

  5. 人工重力仅纸上
    用旋转舱产生离心加速度，替代地球重力。工程上是把居住舱与配重臂连接后整体旋转，但转动带来的科里奥利效应会让人体前庭系统不适，转速与半径必须折中。
    技术详解

    人工重力。长期失重会造成骨密度流失、肌肉萎缩、体液重分布，而人工重力的矛盾是几何：要产生 1g 就得旋转，但半径越小、转速就得越快，而转速一快，科里奥利效应就会让人内耳不适。因此半径至少要百米量级——这个数字直接决定飞船的尺寸，也决定了它只能与大型构型绑定，无法在小型飞船上实现。

    创业视角

    这一环没有近期商业路径，创业者不应把它当主业。可迁移的技术是旋转机构的动力学与舒适性研究，它的现实客户在别处：大型空间站的环境控制、地面的大型旋转模拟设备、以及娱乐与训练用离心机。如果一定要做，姿态是承接地面模拟设备订单、顺带积累旋转环境下的生理数据，而不是等一个飞船订单。死法：把「未来飞船需要人工重力」当作商业前提去做产品——这个需求的时间尺度以十年计，任何以它为主业的公司都撑不到那一天。

  6. 辐射防护仅纸上
    被动路线用富氢材料（聚乙烯、水墙，甚至用饮水与废物充当屏蔽层）；主动路线用超导磁层偏转带电粒子，但需要低温与巨大功率。目前两条都没有可上船的方案，这是唯一还没有解法的环节。
    技术详解

    辐射防护。这是整条链路里唯一连技术路线都不清晰的一环，也是它对一次火星任务影响最大的地方——累积剂量可能超出职业暴露限值数倍。三条候选路线各有硬伤：被动屏蔽（水、聚乙烯、月壤）质量代价极大；主动磁场防护需要兆瓦级电功率；生物医学防护（辐射防护药物、促进细胞修复）还在早期。现实做法是「被动屏蔽 + 缩短暴露时间 + 药物」的组合，而不是等一个完美方案。

    创业视角

    近期没有可行的商业闭环，这一环要直接劝退。唯一有现实路径的切入点是剂量测量与个体化风险评估：能把累积剂量测准、并给出个体风险估计的仪器与模型。这类产品在地面也有客户——核工业、放疗、航空机组人员的职业暴露监测，市场真实且监管明确。死法：给客户一个「防护解决方案」的承诺——现有物理条件下这个承诺无法兑现，交付不了就是信誉破产；能做的是把风险测准并说清楚，而不是消除它。

最难的一环：水和氧已经能闭环，但链路卡在食物与辐射这两环。一次 3 年往返的火星任务，靠地球补给食物在质量上算不过来；而辐射防护至今没有可行方案，是唯一连技术路线都不清晰的环节。

层05技术怎么一步步做Technology Roadmap

下面这五步有先后依赖——前一步的通过判据不成立，后一步就无从谈起，所以顺序不能调换、也不能跳。每一步都写明「要跨的差距 / 具体怎么做 / 需要什么条件 / 通过判据」，判据是可观测的工程事实（试车时长、复用次数、回收率、σ 值），不是进度百分比。

今天在哪

水回收率约 98%、氧与二氧化碳已能闭环（ISS 的 ECLSS 已做到）；食物几乎全部靠地球补给。一次 3 年往返的火星任务，全补给食物在质量上算不过来。

要到哪

    需要的条件空间站上的长期种植实验数据 + 营养液再生技术 + 适合密闭环境的作物品种选育。 通过判据在轨连续（≥1 年）稳定产出，且元素回收率能证明显著减少补给质量。
  4. 废物资源化 5–10 年

    要跨的差距　人体废物、包装、废弃作物目前大部分当垃圾处理，里面的元素白白流失。

    怎么做　微生物或酶解 + 湿式氧化，把有机废物转化成植物可吸收的养分形式；同时必须控制病原与异味——密闭空间里这两件事的权重比地面高得多。

    技术参数取值口径与依据
    手段 酶解 / 湿式氧化 把有机废物转化成植物可吸收的养分
    判据 回收消耗 < 补给节省 否则闭环只是把垃圾换成了电
    额外要求 病原与异味控制 密闭空间里这两件事的权重远高于地面
    需要的条件生物反应器小型化 + 长期运行稳定性验证。 通过判据废物中的关键元素回收率进入闭环计算，并被证明有净收益（回收消耗 < 补给节省）。
  5. 人工重力与辐射防护 10 年以上

    要跨的差距　长期失重带来的骨密度流失、肌肉萎缩、体液重分布，与深空辐射的累积剂量，是长期航行的两大生理风险。两者都还没有可行方案。

    怎么做　人工重力的矛盾是几何：要产生 1g 就得旋转，但半径越小转速就得越快，而转速一快科里奥利效应就会让人内耳不适——所以半径至少要百米量级，这直接决定飞船的尺寸。辐射防护的三条候选路线各有硬伤：被动屏蔽（水、聚乙烯、月壤）质量代价极大；主动磁场防护需要兆瓦级电功率；生物医学防护（辐射防护药物、促进细胞修复）还在早期。现实做法是「被动屏蔽 + 缩短暴露时间 + 药物」的组合，而不是等一个完美方案。

    被动屏蔽 水 / 聚乙烯 / 月壤 质量代价极大
    主动屏蔽 需兆瓦级电功率 磁场方案的门槛

    需要的条件深空辐射环境实测数据 + 百米级旋转结构（若走人工重力）+ 兆瓦级空间电源（若走主动屏蔽）。 通过判据一次完整火星任务剖面的累积剂量与失重暴露被证明在可接受风险范围内。
最硬的一关：辐射防护。其他环节都是「把已知原理工程化」，只有这一环至今连技术路线都不清晰——它和食物闭环的区别是：食物闭环知道要往哪个方向做（元素循环），辐射防护连「主方案是什么」都还没定。而它对一次火星任务的影响是决定性的：累积剂量可能超出职业暴露限值数倍。
回收率与水处理流程为 ISS 公开资料口径；火星任务补给质量为公开研究中的估算量级。

层06创业者路线图Founder Roadmap

水与氧已经闭环，食物与辐射没闭。前者的门槛是体积与能耗、可以做成产品；后者连技术路线都没收敛、只能做研究。所以切入点只能在「食物」这一侧，而且要先用地面市场把产品磨出来。这条链路最容易被讲成浪漫故事，所以先把一句话说死：你的第一笔收入一定来自地面，不是来自航天。

切入点 做闭环里最弱那一环的替代方案——受控生态种植的光配方与营养液控制，或舱内微生物与污染物监测

赛道判断Track Check

客户与付款方
两条腿。地面客户是垂直农场、植物工厂与高端温室的运营方——他们买的是「单位面积的产量」和「每公斤的能耗」，指标非常硬；航天客户是空间站与商业舱的生保承包方，他们买的是可靠性、体积和免维护性。同一个技术平台要能同时讲清这两套话术。
钱从哪来
地面订单（设备 + 耗材 + 服务）养活公司，航天收入按项目计、间隔长。适合自筹加少量产业资本，VC 对这种慢生意兴趣有限。可以补的公共资金有两条：农业口的设施农业补贴、航天口的技术验证专项。
市场量级
地面垂直农业的设备与配套是十亿美元量级且在增长，但竞争激烈、毛利被压得很低，靠它赚钱不容易；航天生保的采购额小（部件级千万级），但单价高、切换成本极高——一个部件一旦被写进生保系统的方案，基本伴随整个型号。
竞争格局
垂直农业的玩家很多，尤其在光配方与营养液控制上——必须承认这一点。所以航天版不能只靠技术差异化，要靠「航天规格下的可靠性与体积能耗优势」，而这恰恰是地面玩家不愿意做的活：为几十台设备的市场去做真空、热循环、振动与十年免维护的认证，账算不过来。
护城河
护城河是长期运行数据 + 认证。地面连续跑三年无故障的记录，是航天采购唯一认可的凭证；同时，一旦你的部件进入生保系统的方案基线，后续改型的沿用几乎是默认的。
这类公司的整体死因
最常见的死因是把地面农业的寿命与维护指标直接套到航天上：地面允许每周停机维护、换泵换灯，船上不行，可靠性和可维修性要求完全不同。第二个死因是空窗期——载人火星任务的采购节奏以十年计，中间有很长的没有项目的阶段，团队会在那段时间散掉。

五个阶段Five Stages

  1. 01 先卖给地面垂直农业 0–12 个月

    做种植舱的「光配方 + 营养液闭环控制」小系统。同一套技术在地面垂直农业有真实付费客户——先在那里把产品做扎实。

    具体怎么做① 先去真实的垂直农场蹲三天（不是看报告）：看他们每天在调什么、因为什么损失一茬菜。光配方和营养液控制这两个方向，90% 的真实痛点只有在现场才看得见。 ② 把「光配方」做成一款能耗账算得清的产品：同样产量下每公斤菜的电费降多少。垂直农业客户只看这一个数字，不看光谱图有多漂亮。 ③ 第一版只做控制与算法，不做灯具和栽培架——那些是红海，而且一旦做了硬件，你就要为它的维修负责，产品会变重。 ④ 客户选中型农场（几百到几千平米），不要选头部（他们自研）也不要选微型（付不起钱）。判据是对方愿意让你接入他的环境控制系统读数据——愿意给数据才算真合作。 ⑤ 记录连续运行的全部数据：故障、误报、漂移、维护次数。航天客户将来问的第一件事就是「这东西连续跑了多久、出过什么故障」。

    卖什么给谁卖系统与耗材（营养液配方、灯板、控制模块），按种植面积或按套计价。地面客户关心投入产出比，所以定价要能算出一年的回本周期。 这一步要投多少需要植物生理 + 环控 + 电子的三人配置，启动资金几百万：做一套能跑起来的种植舱验证平台就是主要开支。 通过判据地面客户复购，且产品经受住连续运行考验——复购是这套技术真的有价值的唯一证据，一次性采购可能只是尝鲜。 这一步的死法一上来就按航天规格做，成本下不来、也没有客户敢用没飞过的系统。

    止损线18 个月内，地面客户里没有一家愿意为第二套系统付钱——说明你的产品在地面市场也没有竞争力。这时候要么换指标（比如专攻能耗），要么承认这条路不通。

  2. 02 用地面收入养航天版本 12–30 个月

    把体积、能耗、可靠性按航天要求重做，同时用地面订单摊薄研发。这一步的关键是「同一平台两个版本」，不是两条独立产品线。

    具体怎么做① 把「同一平台两个版本」落到工程上：核心算法与控制逻辑一份，硬件与结构做两套。两条独立产品线会让你两边都做不好。 ② 航天化的改动其实只有四件事：减体积、减能耗、抗振动、可维修。逐条列成改动清单，并按「改起来最贵的排前面」去排优先级——往往是结构先动，算法几乎不动。 ③ 环境试验要提前找有资质的第三方实验室询价排期（真空、热循环、振动三项），一套下来几十万量级、周期 3–6 个月。先报价再设计，让成本约束指导方案。 ④ 元器件替换是隐形大头：商用件换宇航级，价格可能涨十倍、交期可能到 26 周以上。这一步要在设计冻结前完成。 ⑤ 地面订单必须同时还在增长，否则你就是在用现金流赌航天，而航天采购的节奏不会照顾你的现金流。

    卖什么给谁地面版继续出货赚钱；航天版卖工程样机与试验服务。航天侧在通过环境试验前基本没有营收，所以地面收入的强度决定这一步能不能走完。 这一步要投多少环境试验本身很贵（每次几十万到百万级），需要一份能覆盖两到三轮试验失败的预算，不能只做一次的钱。 通过判据航天版通过环境试验（真空、热循环、振动）——这三项是硬门槛，过不了就没有资格谈上船。 这一步的死法航天版做成全新设计，等于从零再来一次，地面收入根本不够烧。

    止损线航天版的累计研发投入超过地面业务两年利润——这时候应该停下，先回地面把利润做厚，而不是靠融资填窟窿。

  3. 03 做舱内环境与微生物监测 30–48 个月

    闭环系统真正的杀手是污染与菌群失衡，而不是设备停机。做成可上船的传感器与快速检测试剂盒。

    具体怎么做① 先做误报率，再做灵敏度。舱内监测产品死在误报上的比死在漏报上的多得多——乘组被误报折腾几次之后，设备就会被关掉，而关掉的设备等于零。 ② 产品形态选「采样 + 快速检测」的组合：连续在线传感器负责趋势，试剂盒负责确认。纯在线方案在舱内标定困难，纯试剂盒方案又太慢。 ③ 在真实环境里积累基线数据：地面模拟舱、潜艇、洁净室、冷链仓——这些地方的环境背景与舱内更接近，而且愿意让你装设备。 ④ 把误报与漏报画成一条 ROC 曲线，明确写出你选择的工作点以及为什么。采购评审会问这个，答不上来等于没有可靠性论证。 ⑤ 同时卖给制药、生物实验室、食品厂——他们的洁净度要求与舱内同类，而且付款比航天快得多。

    卖什么给谁卖传感器 + 试剂耗材（典型的刀架与刀片模型）：传感器一次卖、试剂反复卖，收入可持续。地面客户同样存在这个需求——洁净室、生物实验室都要用。 这一步要投多少需要微生物与仪器两个方向的团队，以及一段真实封闭环境里的验证时间。年成本千万以内。 通过判据在长期模拟舱（地面封闭实验）里连续运行数月无重大误报。误报率是这类产品的生死指标，误报多到乘组不愿意用，就是废品。 这一步的死法指标照搬地面实验室标准，误报率高到乘组不愿意用。

    止损线在模拟舱里误报率始终下不来，同时地面市场的同类产品已经做成白菜价——这条产品线该砍掉，把资源集中回种植系统。

  4. 04 参与长期封闭模拟试验 4–6 年

    进入地面模拟舱项目（多人、数月量级），拿到「长期运行数据」这个别人没有的资产。这类数据是航天采购唯一认的凭证。

    具体怎么做① 主动去已有模拟舱项目的单位问「你们缺什么测点」。进这类项目的正确姿势是补一个别人没做的短板，而不是带一整套方案去要求替换。 ② 目标是拿到数月期连续运行记录。为此可以免费提供设备与运维人力，但要在协议里写明数据使用权与你能否公开发表——这一条比设备款重要。 ③ 数据必须能被第三方复核：原始时间序列、标定记录、维护日志、异常说明。只给结论的报告在采购评审里没有分量。 ④ 同步把数据写成论文或会议报告。公开可复核比内部数据值钱得多，因为采购方只认可核验过的结论，而且这会给你带来下一批合作方。 ⑤ 这一段可能要等 2–3 年才有下一次机会，期间用地面业务养着，别解散团队——这类能力一旦散掉很难重建。

    卖什么给谁作为设备与数据供应方参与模拟项目，收设备费 + 数据服务费。这一步的营收不大，但它买到的是采购资格。 这一步要投多少要有能长期驻场的技术人员，以及和科研机构一起申报项目的行政能力。这一步拼的是耐心和关系，不是钱。 通过判据有一段被第三方认可的多月期连续运行记录，并且能写进标书——不是自己发的新闻稿。 这一步的死法只做短周期演示，数据在采购评审里不被采信。

    止损线连续两轮模拟项目都拿不到正式的数据署名或使用授权——你只是在给别人做免费设备。要么争取署名，要么退出这类合作。

  5. 05 走到生保系统集成 6 年以上

    从部件供应商走到生保系统集成商。要有耐心——载人火星任务的采购节奏以十年计，中间会有很长的空窗期。

    具体怎么做① 系统集成的前提是你已经有了两个以上被验证过的部件。只有一个部件的公司去做集成，会被客户当成「想当总包的分包商」。 ② 集成的核心能力是接口定义与故障隔离，不是把所有东西自己做。要主动把一部分子系统留给别人，并帮客户建立「多供应商」的信任——这在航天采购里是加分项，因为客户最怕单点依赖。 ③ 载人火星任务的采购节奏以十年计，中间会有很长的空窗期。跨过这段空窗的办法是把系统集成能力用到地面：生物安全实验室、密闭设施、深海与极地科考站，这些都是同一套接口与可靠性工程。 ④ 系统级合同通常要求你承担总体可靠性指标，要提前买产品责任险，并在合同里把「不可控的第三方部件故障」的责任边界写清楚。 ⑤ 判据是拿到第一个系统级合同，而不是参与过某个系统的某个部分。

    卖什么给谁系统级承包（设计 + 集成 + 保障），单价上一个数量级，但要有能力承担系统级风险与质保。 这一步要投多少系统集成要有一支多专业队伍与一套完整的质量体系，年成本数千万起，通常需要战略股东或国资背景才能承接。 通过判据拿下第一个系统级（而非部件级）合同。 这一步的死法在空窗期把团队解散，等采购启动时已经没有承接能力。

    止损线空窗期超过三年、且没有任何邻接市场（如地面生物实验室、制药洁净工程）能养住团队——这时候应该收缩为部件公司，不要硬撑系统集成商的架子。

最该避免：不要做辐射防护创业：它连技术路线都没收敛，是研究课题不是商业课题。也不要把地面农业的寿命与维护指标直接套到航天上——可靠性和可维修性要求完全不同。
地面垂直农业与航天生保的关键部件高度重合，这是这条链路能商业化的根本原因。但要注意两者的市场逻辑完全相反：地面拼成本，航天拼可靠性。同一套技术、两套话术，不能混着讲。
通用零基础起步：从没有公司到第一笔收入十个步骤

下面这些和具体方向无关。不管最后选了哪条赛道，注册、找客户、报价、签合同、分股权、管现金这六件事都要做一遍，而且顺序不能颠倒——先注册再找客户、或者先买设备再谈第一单，都是很常见也很贵的顺序错误。每一节末尾都写了「最常见的错」，那些基本都是别人已经付过学费的。

  1. 00先花一个小时判断这件事适不适合你

    创业不是一种身份，是一段要连续几年做同一件不性感的事的状态。先做个减法，不合适就别开始——这比任何技术准备都省钱。

    • 第一个问题：在没有工资的情况下，你能撑 18 个月吗？（算上房贷、生活、社保，把数字写下来，不要凭感觉）。撑不住就先别辞职，用业余时间做验证。
    • 第二个问题：你手上有没有一条能直接接触到目标客户的渠道？（前同事、老客户、行业里的人）。没有渠道的创业，等于从零开始学两件事：做产品 + 找客户，失败概率会翻倍。
    • 第三个问题：你打算做的这件事，是你自己想出来的，还是客户说出来的？自己想出来的方案，通常要花两年才明白客户要的不是这个。
    • 如果三个问题里有两个答不上来，先别注册公司，去把第 01 节做完。

    最常见的错把「想当老板」「想赚钱」「不想上班」当成创业理由。这三个理由都撑不过第一年的第 8 个月——那时候钱快花完了，客户还没签，支撑你继续的只能是「这个问题真的存在，而且我有一个别人没有的解法」。

    自查成本：0 元。代价：想不清楚就动手，通常要花掉 1–3 年。

  2. 01注册公司之前：把问题钉死

    这一步不需要公司、不需要产品、不需要花钱。它的唯一产出是一张表——证明「有人愿意为这件事掏钱」。

    • 写一句假设，格式固定成：{某个职位的人}，在 {某个场景} 下，因为 {某个问题}，每年要花 {多少钱或多少时间}，现在的解法是 {什么}，最烦的是 {哪一点}。写不出来就说明还没想清楚。
    • 拿着这句话去找 10 个真实的目标客户聊。注意是客户，不是朋友、不是同行、不是投资人。每个人聊 30 分钟，只听、只问，不推销。
    • 必问的三个问题：① 这件事你们现在是怎么解决的？② 一年大概花多少钱、或者多少人力在这上面？③ 最让你难受的是哪一步？
    • 把 10 次访谈记成一张表：姓名 / 单位 / 职位 / 现在的解法 / 每年花费 / 最烦的一点 / 是否愿意试我们的东西。这张表就是你第一版的商业模型。
    • 过关标准：10 个人里至少有 3 个人主动问「你这个能不能卖给我」「什么时候能给我用」。如果 10 个人都只是礼貌地说「挺好的」，那就是礼貌的拒绝，不是需求。

    最常见的错先做产品再找人聊。你会做出一个技术上很漂亮、但没人需要的东西，而且因为已经投了时间进去，你会不自觉地替它辩护，更难承认看错了方向。

    这一阶段花 0–1 万元（差旅、请人喝咖啡），2–3 个月。这三个月能省掉后面一到三年。

  3. 02注册公司：选什么类型、要花多少钱

    公司是为了签合同、开发票、交社保才注册的，不是为了「像个公司」。所以顺序是：确认有人要跟你签合同了，再注册。

    • 类型选有限责任公司（含一人有限公司），不要选个体户。个体户是无限责任，而且航天、工业这类客户基本不接受个体户签采购合同、也开不出增值税专用发票。
    • 注册资本别写高。 现在是认缴制，写 100 万不等于要马上交 100 万，但这 100 万是你承担的有限责任上限、也要在承诺期限内实缴。50–100 万是常见写法；写 1000 万只会让你在投标时被质疑履约能力。
    • 在本地政务服务网（一网通办）自己办是 0 元，3–10 个工作日拿照；找代办 500–2000 元省事。刻章 200–500 元。
    • 拿到执照后必须连着办三件事：① 银行开基本户（0–1000 元/年）；② 税务登记，同时决定做小规模纳税人还是一般纳税人——客户要增值税专用发票，你就必须是一般纳税人；③ 社保开户（要雇人就得交）。
    • 找个代理记账，200–500 元/月。这笔钱不要省：自己记账的结果通常是报税逾期被罚，或者根本算不清公司到底赚不赚钱。

    最常见的错一上来就租办公室、买设备、招人。这些东西应该等到有收入之后再买——第一年你 90% 的时间在外面见客户，工位只用得到一张桌子。共享办公或自家客厅能撑到第一笔订单。

    注册相关的总花费 3000–8000 元，之后每月固定成本（记账 + 社保 + 银行）1000–3000 元。

  4. 03找到第一个客户：这一步没有捷径

    第一个客户的价值不是那笔钱，是它证明了你的事有人要。找到它平均要接触几十个线索、花 3–9 个月，这是正常速度，不是你不擅长销售。

    • 先列名单，再联系。 名单从这些地方来（都是公开的）：行业展会的参展商名录、协会/学会的会员名录、招投标平台上的历史中标公告（谁在中标 = 谁在花钱买这类东西）、专利数据库（谁在申请相关专利 = 谁在做这件事）、招聘网站（谁在招这个岗位 = 谁有这块业务）。目标：先凑出 60–100 个真实单位、以及其中 20–30 个具体到人名和职位的人。
    • 要联系的人是技术口：总师、主任设计师、工艺主管、实验室负责人。不是采购部。这个行业拿单的顺序永远是「技术口先认可 → 质量体系过审 → 采购走流程」，跳过技术口直接找采购，你的资料会被归到「待评分供应商库」里再也出不来。
    • 第一封邮件控制在 200 字以内，只写五句：我是谁 / 我注意到你们在做 X / 我以前在 Y 做过同类的事 / 我有一个可能帮你们省 Z 的具体想法 / 想占用你 20 分钟。不要附 PPT、不要写「我们技术先进」，技术人会直接删掉这类邮件。
    • 第一次见面不要介绍你的方案。带三个问题去，把 30 分钟全用来听：你们现在这块怎么做？卡在哪一步？一年大概多少量？（客户说得越多，你后面报的价越准。）
    • 跟进的节奏决定成败：第一封邮件 4 天后打一次电话；之后每 2 周跟进一次，至少跟 6 次。大多数人只发一次邮件就放弃，而成交往往发生在第 5–6 次接触。

    最常见的错群发邮件、发朋友圈找客户、指望中间人替你谈。前两个的转化率接近 0，第三个的问题是——中间人替你谈成的单，你后面永远绕不开他。

    第一个客户通常要接触 30–100 个线索、耗时 3–9 个月。旅差成本 1–3 万元。

  5. 04报价、谈钱、开发票、催回款

    新手最容易在这四件事上把已经谈成的单子做亏。技术出身的创始人有一半会在第一次报价时报低于成本。

    • 先把成本算出来，再报价。 公式：直接材料 + 直接人工（按工时 × 你的真实时薪，不是月薪除以 22 天）+ 差旅 + 30% 的管理与风险附加 + 税（一般纳税人增值税 13%，还有企业所得税）。把公司固定成本也摊进去。
    • 报三个价，让客户有得选：① 最小方案——只解决一个问题、最便宜，用来降低对方的决策门槛；② 标准方案；③ 含服务的方案。先卖最小方案，因为新人拿不到大单，而小单能让你进入对方的视野。
    • 付款条件写死在三段：预付 30–50%（开工前到账）、交付 40–50%、验收后 10–30%。
    • 没有预付款的单子不要接。这是新手最常犯的错：自己垫钱、垫材料垫人力，客户验收拖延三个月，你的公司就死在现金流上，而不是死在技术上。
    • 报价单上必须写清：含什么、不含什么、工期、付款节点、报价有效期（一般 30 天）、是否含税。尤其是「不含什么」——需求一旦超出范围，要按变更单加钱，而这条必须事先写出来。
    • 回款：合同里写「验收后 N 日内付款，逾期按 LPR 计息」；到期前 3 天发一次提醒，逾期后每周跟进一次、只走邮件（留下书面记录，将来要打官司用得上）。只在微信上催，半年后你拿不出证据。

    最常见的错把客户的预付款当成收入或利润花掉——那是负债，它对应的交付还没发生。另一个常见错是接受「验收满意后一次性付款」，等于把全部风险揽到自己身上。

    航天、工业客户的实际回款周期通常 3–9 个月。所以账上要随时留够 6 个月的现金。

  6. 05签第一份合同：谁来写、要看哪几条

    合同不是走流程，它是你唯一能在对方拖欠、改需求、跑单时保护自己的东西。原则只有一条：用你自己的模板。

    • 合同由你来写。 用客户给的模板意味着条款永远把风险推给你：验收标准模糊、付款条件挂在他的流程上、违约只约束你一方。自己被拒绝也不要紧——把关键条款谈掉，通常比换模板容易。
    • 六条必须逐条读：① 验收标准要可测（「检测报告符合 XX 标准」，不能是「满足甲方要求」）；② 付款节点与条件；③ 变更怎么算钱（需求一改就要加钱、延期）；④ 违约责任是否对等；⑤ 知识产权——你的背景技术归你，项目成果可以给客户；⑥ 争议解决地尽量约定在你所在地。
    • 要不要请律师：单笔 50 万以内的常规采购合同，用行业模板 + 自己逐条读，一般够；超过 100 万，或者涉及知识产权独占、独家代理、对赌回购的，花 2000–5000 元请律师看一遍——比后面赔几十万便宜得多。
    • 合同之外的所有约定都要落进纸面。微信上谈定的工期、加急、「先做着钱后面补」——统统不算数，要么补一条补充协议，要么走变更单。

    最常见的错先干活、后补合同。等你要签的时候，条款全由对方定，而且你已经把成本沉进去了，谈判筹码为零。顺序永远是：签合同 → 收预付款 → 开工。

    合同律师审阅 2000–5000 元/份。省这笔钱的代价通常是一个季度的利润。

  7. 06找人和分股权：前三个人的做法决定公司能不能活

    早期招人最大的误区是想招「厉害的人」；正确的是招能各自独立扛住一块的人，而股权分错是新手公司最常见的死法，没有之一。

    • 前三个人的画像：① 一个能独立把交付做出来的技术；② 一个能独立面对客户的人（可以是创始人自己）；③ 一个能把东西真做出来的人（工艺、生产、测试）。不要先招行政和财务——代理记账 + 你自己就够了。
    • 从哪找：前同事的成功率最高（你了解他的能力、他也信你），其次是客户和供应商推荐，再次是行业会议和技术社区。不建议在招聘网站等简历——早期你竞争不过大厂，等来的多半是待不住的。
    • 给什么：现金（尽力给到市场价的 60–80%）+ 期权 + 一件能学到东西的事。给不起钱要用期权补，但要诚实地说明「公司失败的话它一文不值」，含糊其辞的承诺后面一定会变成怨气。
    • 股权三条基本规则： ① 必须有一个人的持股（或投票权）超过 50%，平均分（50/50、33/33/33）会让公司在两个创始人意见相反时直接瘫痪；② 给核心员工用期权而不是实股，4 年成熟、1 年 cliff（干满一年才拿到第一批）；③ 创始人之间必须签股东协议，写清退出机制、股权回购、竞业与保密。
    • 不要给「顾问」白送股份。一次微信上的咨询就换来 5% 股份，将来每一轮融资都要为这 5% 做解释，而且他不会再出现。顾问按次付费或给千分之几的期权。

    最常见的错给兼职的人股份；口头承诺「以后给你 10%」但不落纸；一上来就把股权全分完、不留期权池（后面招不到人）。

    早期期权池留 10–15%；找律师做股权架构与股东协议 5000–2 万元。

  8. 07管现金：把「还能撑几个月」变成每天都能答出来的数

    公司死掉的原因排第一的是现金流断了，不是技术失败。这件事必须变成一张你每周都看的表。

    • 每月做一张表，五个数：月初现金 / 本月收入 / 本月支出（按科目列）/ 月末现金 / 应收账款（谁欠多少、欠了多少天）。代理记账给的报表不能替代它——那是给税务看的，不是给你做决策的。
    • 每周看三个数：账上现金、本月净流出、还能撑几个月（= 现金 ÷ 月净流出）。第二个数算不出来，说明你不知道钱花在哪。
    • 设三条线：撑不到 6 个月 → 停掉一切非必要支出（展会、设备、差旅标准）；撑不到 3 个月 → 开始裁人或找钱；撑不到 1 个月 → 只剩一件事：把应收账款收回来。
    • 个人和公司的钱严格分开。 公司账户不要付私人开销（税务风险），也不要用个人信用卡给公司垫钱——你会永远算不清公司到底赚不赚钱，而且垫进去的钱基本回不来。
    • 把每月固定成本背下来（记账 + 社保 + 房租 + 最低工资）。这个数字是你判断「这单该不该接」的底线。

    最常见的错把客户的预付款当利润花掉；用网贷/信用卡给公司救急（这是无底洞，利息会吃掉你所有的可能性）；不记账，靠账户余额判断公司好不好。

    每月固定成本要能背出来；现金缓冲目标 6 个月。

  9. 08什么时候融资、跟谁融

    融资不是创业的目标，是加速器。方向没验证之前融资，等于花钱把错误放大。

    • 不该融的时候：还没有付费客户；还没想清楚卖什么；唯一的原因是「缺钱发工资」。这三种情况下融资只会让你被迫讲一个更大的故事，然后被这个故事绑架。
    • 该融的时候：有 3 个以上付费客户、有复购或转介绍在发生、你缺的是产能和人，而不是方向。这时候钱能立刻变成增长。
    • 先拿不占股份的钱：科技型中小企业 / 专精特新认定、地方研发补贴、首台套保险补偿、银行科技贷（很多地方贴息 50%）。这类资金申报周期长但不要股份，适合和客户订单并行推进。
    • 跟谁融：早期优先产业资本（客户所在行业的集团投资部、上下游上市公司）和地方产业基金——他们对「国产替代 + 硬科技」的接受度最高，还常常带来订单和资质。纯粹看财务回报的 VC 对重资产长周期项目通常没兴趣，不用在这上面耗时间。
    • 准备材料（一页纸就够）：我们是谁 / 解决什么问题 / 给谁用 / 怎么收钱 / 已有几个客户、多少收入 / 需要多少钱、花在哪、下一阶段的判据是什么。再加证照、财务流水、脱敏后的客户合同。
    • 融资到账通常要 4–9 个月，所以启动融资时账上至少要有 9 个月现金，否则你会被迫接受很差的条件。

    最常见的错接受带个人连带责任的对赌或回购条款——公司失败会追到你个人资产。另一个错是为了融资把产品方向改成投资人喜欢的样子，那基本等于换了一家公司重做。

    早期股权融资量级 300–2000 万元，对应 10–30% 股份。

  10. 09换方向，或者体面地关门

    关门不是失败，把一家已经没有可能性的公司拖成负债、拖散团队、拖坏个人信用才是。

    • 该换方向的信号：连续 12 个月拿不到任何付费客户；客户都说「这个好东西」但没人掏钱；每一单都要重新定制，导致规模永远上不去、毛利永远像服务业。出现两个就要认真考虑。
    • 该关门的信号：账上现金撑不到 2 个月且融不到钱；应收账款大面积收不回；核心团队已经散了。
    • 如果决定关：先结清员工工资和社保（这是法律义务，清偿顺序最靠前），然后处理客户未交付的合同（协商退款或转让给同行），再是供应商货款，最后才是股东。不要借新的钱去还旧的钱。
    • 把失败的原因写成一份文档：当初的假设是什么、哪个假设被证伪了、钱主要花在哪、哪个判断现在回头看是错的。这是你下一次创业最值钱的资产，比任何行业报告都有用。

    最常见的错拖着不宣布（团队和供应商会同时失去耐心）、突然消失（这个行业的圈子很小，名声会跟着你十年）、或者用新项目的钱填旧项目的坑。

    清算通常需要 3–12 个月，律师与清算费用 1–5 万元。

4.2 闭环做到了什么程度

ISS 的环境控制与生命保障系统（ECLSS）是人类目前最成熟的再生式生保系统。它由三大件组成，分别管水、空气和氧。

三大件与它们的相互关系

水回收系统（WRS）负责把一切能回收的水捞回来：尿液、舱内湿气冷凝水、舱外活动服里的水。尿液先经过尿处理装置，在旋转鼓里做低压真空蒸馏——用离心模拟重力，让水蒸气与浓缩盐水分离；蒸馏水再和其他废水一起进入水处理装置，经过多层过滤床和高温催化氧化器，最后出来的水比多数城市的自来水更纯。

空气再生系统用沸石分子筛吸附舱内的二氧化碳，饱和后暴露在太空真空里加热再生、把 CO₂ 释放出去。

制氧系统用电解把水拆成氧和氢。氧进舱，氢原本直接排掉。

后来加装的 Sabatier 反应器把两股「废物」接了起来：氢 + CO₂ 生成水和甲烷，水回到水回收系统，甲烷排掉。这一步把呼出二氧化碳里约一半的氧重新捞了回来，是闭环率提升的关键一跳。

阶段水回收率关键改动意义
早期航天器水星—航天飞机 不回收 开环，全部从地球携带 任务时长被补给质量直接限死

氧的闭环做得没有水好，目前大约一半：靠电解回收水，再靠 Sabatier 把呼出二氧化碳里的一部分氧捞回来，剩下的靠补给与消耗品。食物则完全没有闭环——全部从地球运上去。

ISS 长期运行给出的最重要一条工程教训，不是「要做到理论完美」，而是「在轨可维修性比理论性能更值钱」。再充分的 ground test 也预测不到微重力下连续运行数年会长出什么问题。真正的保障是：系统降低效率也还能跑，乘员手上有零件和工具能修。

这条教训在火星航段会被放大到残酷的程度——ISS 上最坏的情况是「几小时内可以撤离」；火星航段没有这条退路。

4.3 辐射：唯一还没有解法的问题

如果把所有深空医学问题排个序，辐射是唯一一个公认「目前无解」的。ESA 与 NASA 的研究者在这件事上的措辞几乎一致：我们还没有找到有效的屏蔽手段。

地球有大气层和磁场两层庇护，ISS 还额外待在磁场保护范围内。一旦脱离近地轨道，威胁分成两类：

  • 银河宇宙射线（GCR）——高能重离子，能量极高、穿透力强，被动屏蔽几乎拦不住，反而会在屏蔽体内产生次级粒子。
  • 太阳粒子事件（SPE）——太阳耀斑抛出的高能质子流，强度大但可以被一定厚度的物质挡住，问题是需要提前预警并有一个「辐射避难所」。

屏蔽手段的现状

水墙、聚乙烯等富氢材料对 SPE 有效，对 GCR 效果有限；磁场屏蔽在理论上可行，但需要的磁场强度与线圈质量让它在工程上还没有落地。ISS 上有个很有说明性的先例：风险评估发现老旧俄制舱段的屏蔽能力较差、对整站构成不成比例的威胁，于是专门组织了一系列太空行走，在发射多年之后给这些舱段加装了附加屏蔽板。

这件事的推论很直接：未来长时程栖息地的外壳不能被当作一次定型的固定设计。它必须允许在任务过程中被检测、被修复、被升级——因为威胁环境和我们对它的理解都会变。

一个反直觉的联系

冬眠可能提供部分辐射保护。冬眠动物代谢率极低、组织含氧量下降、DNA 紧密缠绕，同时具备强力的 DNA 修复机制。低氧本身会提升对辐射的耐受力。这是把板块六（冬眠）和板块四（栖息地）连起来的一条线：降低代谢，可能同时降低辐射伤害。

4.4 微重力的代价与人工重力

微重力不是「失重的浪漫」，它是一组持续累积的生理损耗。时间越长，这些损耗越难靠锻炼和药物对抗。

已经观测到的损耗

  • 骨密度——承重骨每月流失约 1% 到 1.5%，量与绝经后骨质疏松的速率相当；返回地球后恢复缓慢且不完全。
  • 肌肉——不做对抗训练就快速萎缩，抗阻训练只能部分抵消。
  • 视力——体液向头部转移导致颅内压变化，部分航天员出现视神经盘水肿与视力改变（SANS），机制仍未完全清楚。
  • 体液与心血管——血液重新分布、心脏形态改变，返回后立位耐力下降。
  • 免疫与微生物组——免疫系统功能改变，同时封闭环境里的微生物群落结构发生变化。

人工重力：不是能不能做，是划不划算

靠旋转产生离心加速度，物理上很简单。工程上的取舍在两个参数上：半径越大、转速越慢，人越舒服；转速超过约每分钟 2 转，多数人会出现前庭不适与眩晕。而「慢转速 + 1g」意味着半径得有几百米量级——这对结构、对接、姿态控制都是巨大负担。

折中方案是降低人工重力水平，比如 0.3g 到 0.5g 配合运动对抗，或者在航程中交替使用旋转与非旋转舱段。这些都还是方案阶段。

把这一节和板块六连起来看：如果冬眠把人体的代谢压在极低水平，那么骨流失、肌肉萎缩、体液转移这些「损耗型」问题在航行期间就被大幅减速了。这也是冬眠在深空航行中被高度重视的原因之一——它不只是省食物，它同时是对抗微重力与辐射的一种手段。

4.5 现实检查

ISS 至今仍然依赖地球补给。真正自持的生态圈——包括食物生产在内——从未在轨完整验证过。
  • 水的闭环 98% 是真实成就，但它是在「可以随时补货、可以几小时内撤离」的前提下达成的。把这个系统搬到火星航段，可靠性要求会提高一个数量级。
  • 氧的闭环只有一半左右，食物闭环为零。所谓「飞船生态圈」，目前最准确的说法是：一个把水和空气部分闭环的维生系统，加上从地球带来的全部食物。
  • 闭环系统的失效模式往往是渐进的：蒸馏装置被矿物沉淀堵塞、分子筛阀门失灵、痕量污染物缓慢累积（症状是非特异的头痛与眼部刺激，溯源经常要几周）。在 ISS 上这些都不致命；在没有补给、没有撤退通道的航段上，任何一个都会变成任务级风险。
  • 辐射没有解法，人工重力还在方案阶段。这两件事决定了「载人深空航行」目前仍是研究课题，不是工程排期。
